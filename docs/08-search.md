# 08. Поиск

## Быстрый поиск

Иконка поиска сверху (или горячая клавиша `Cmd/Ctrl+K`) открывает поле ввода — по умолчанию поиск идёт по
**заголовкам** документов и работает мгновенно, по мере набора текста. Результат — список с иконкой типа
документа, названием и путём по папкам; клик открывает документ.

Когда поле поиска пустое, показывается панель «Последние документы» — 20 недавно изменённых заметок, таблиц и
диаграмм, отсортированных по времени правки. Удобно, чтобы быстро вернуться к тому, над чем работали только что.

## Поиск по содержимому

Флажок «Искать в содержимом» под полем ввода переключает поиск с заголовков на полный текст — теперь находятся
документы, где искомое слово встречается где угодно в теле заметки или в ячейках таблицы, даже если его нет в
заголовке. Такой поиск чуть медленнее заголовочного, поэтому включён не по умолчанию.

## Как формулировать запрос

- Несколько слов ищутся как набор — находятся документы, где встречаются все (или большинство) слов запроса.
- Результаты отсортированы по релевантности — чем точнее и чаще совпадение, тем выше документ в списке.
- PDF-файлы тоже участвуют в поиске по содержимому — текст извлекается автоматически при добавлении файла в
  хранилище, включая PDF без текстового слоя (через распознавание, см. главу [09](09-native-platform.md)).

## Где ещё встроен поиск

- **Поиск по графу связей** — отдельное поле внутри вкладки графа, фильтрует узлы по названию, не относится к
  полнотекстовому поиску (глава [07](07-graph.md)).
- **Фильтр дерева** — кнопка «Фильтр» над деревом (избранное / расшарено со мной) — это фильтрация уже открытого
  списка документов, а не поиск по содержимому.
- **Поиск внутри открытой заметки** — `Cmd/Ctrl+F`, пока курсор в редакторе, подсвечивает совпадения прямо в
  тексте документа.
