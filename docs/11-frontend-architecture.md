# 11. Рабочее пространство и горячие клавиши

## Дерево папок

Слева — иерархия папок со всеми документами хранилища. Правый клик по пустому месту или по папке открывает
контекстное меню: новая заметка/таблица/диаграмма/папка, переименование, перемещение, удаление, «Закрепить»
(поднять папку наверх списка).

Перетаскивайте документы и папки мышью, чтобы переносить между папками; перетащите один документ на другой, чтобы
сгруппировать оба в новую подпапку.

## Множественный выбор

`Shift`+клик — выделить диапазон подряд идущих элементов, `Cmd/Ctrl`+клик — добавить/убрать отдельный элемент из
выделения. С несколькими выделенными документами доступны массовые действия через контекстное меню: удалить,
скопировать, переместить в папку, создать сводную таблицу из выбранного (глава [05](05-sheets.md)).

## Пространства (workspaces)

Переключатель пространств — полоска вкладок над деревом. Пространство — независимый верхнеуровневый раздел внутри
одного хранилища: удобно, например, разделить «Личное» и «Работа» так, чтобы дерево не смешивало документы из
разных сфер жизни, оставаясь при этом в одном зашифрованном хранилище с одним паролем.

Создать новое пространство — «+» на полоске переключателя; переименовать/удалить — правый клик по вкладке
пространства.

## Вкладки и сплит

Открытые документы — вкладки сверху области редактирования, как в браузере: `Cmd/Ctrl+клик` по документу в дереве
открывает его в новой вкладке, не закрывая текущую. Крестик или средний клик мышью закрывает вкладку.

Кнопка сплита делит область редактирования на два независимых столбца — можно держать открытыми два документа
одновременно (например, заметку и связанную таблицу). Флажок «Синхронизировать прокрутку» листает оба столбца
вместе.

При перезапуске приложения все открытые вкладки и разбиение на столбцы восстанавливаются такими же, какими были
при закрытии.

## Тяжёлые документы открываются чуть медленнее в первый раз

Таблицы, диаграммы, просмотрщик PDF и граф связей подгружаются в момент первого открытия за сессию — это не сбой,
а особенность работы: приложение стартует быстрее, а тяжёлые модули появляются только когда действительно нужны.
При повторном открытии в той же сессии задержки уже не будет.

## Горячие клавиши

| Действие | macOS | Windows/Linux |
|---|---|---|
| Быстрый поиск | `Cmd+K` | `Ctrl+K` |
| Новая заметка | `Cmd+N` | `Ctrl+N` |
| Поиск в открытом документе | `Cmd+F` | `Ctrl+F` |
| Жирный / курсив / зачёркнутый | `Cmd+B` / `Cmd+I` / `Cmd+Shift+X` | `Ctrl+B` / `Ctrl+I` / `Ctrl+Shift+X` |
| Отступ / выступ списка | `Tab` / `Shift+Tab` | `Tab` / `Shift+Tab` |
| Отменить / вернуть | `Cmd+Z` / `Cmd+Shift+Z` | `Ctrl+Z` / `Ctrl+Shift+Z` |
| Закрыть вкладку | `Cmd+W` | `Ctrl+W` |
| Множественный выбор в дереве | `Shift`/`Cmd`+клик | `Shift`/`Ctrl`+клик |

## Тема оформления

Переключатель тёмной/светлой темы — Настройки → Внешний вид.
