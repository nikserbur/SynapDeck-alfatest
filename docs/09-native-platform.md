# 09. Голос, распознавание и PDF

## Диктовка (голосовой ввод)

**На macOS** приложение поддерживает диктовку прямо в редакторе: значок микрофона на панели инструментов заметки
запускает распознавание речи — говорите, текст появляется по мере распознавания, повторное нажатие останавливает
запись. При первом использовании система спросит разрешение на доступ к микрофону и распознаванию речи — их нужно
разрешить один раз.

**На Windows** используйте системную диктовку — сочетание **Win+H** открывает панель распознавания речи прямо в
активном поле, включая редактор SynapDesk. Отдельной кнопки в приложении для Windows нет, но результат работает
идентично — текст печатается туда, где стоит курсор.

## Озвучка заметок (текст в речь)

Кнопка озвучки в панели заметки читает текст вслух — удобно, чтобы прослушать длинную заметку или PDF, не читая
глазами. Во время чтения показывается прогресс по сегментам текста и кнопка «Стоп». По завершении можно
экспортировать озвученный текст в аудиофайл (MP3) кнопкой рядом с плеером — например, чтобы слушать заметку в
дороге без открытого приложения.

Для очень длинных заметок текст автоматически разбивается на части по границам предложений — озвучка начинается,
не дожидаясь обработки всего текста целиком.

## Распознавание текста на изображениях (OCR)

При вставке картинки со снимком текста (скриншот, фото документа, скан) можно распознать в ней текст через
контекстное меню картинки → «Распознать текст» — результат вставляется рядом как обычный редактируемый текст.
Поддерживаются русский и английский языки одновременно, языки распознаются автоматически. Работает офлайн, без
отправки изображений куда-либо.

То же самое распознавание используется автоматически для PDF-страниц, у которых нет текстового слоя (например,
отсканированные документы) — чтобы такие PDF тоже участвовали в полнотекстовом поиске (глава [08](08-search.md)).

## Проверка орфографии

Редактор заметок подчёркивает слова с опечатками волнистой линией — правый клик по подчёркнутому слову показывает
варианты исправления, как в любом текстовом редакторе. Язык проверки соответствует системному языку ввода.

## PDF: просмотр, вставка и экспорт

- **Просмотр** — клик по PDF-файлу в дереве открывает его встроенным просмотрщиком с постраничной прокруткой,
  масштабированием и поиском по тексту документа (`Cmd/Ctrl+F` внутри просмотрщика).
- **Вставка в заметку** — `![[файл.pdf]]` или через панель вставки — документ появляется встроенным превью прямо
  внутри заметки, без перехода на отдельную вкладку.
- **Добавление в хранилище** — перетащите PDF-файл из проводника/Finder прямо в дерево или в нужную папку — он
  скопируется в хранилище и станет доступен для ссылок, вставки и поиска.
- **Экспорт заметки в PDF** — кнопка «Экспорт» в панели заметки; сохраняет отформатированный текст заметки как
  PDF-файл с поддержкой кириллицы, пригодный для печати или отправки.

## Известные платформенные ограничения

- Диктовка кнопкой в приложении доступна только на macOS; на Windows — через системное Win+H (см. выше).
- Распознавание текста на изображениях и озвучка доступны на macOS в полном объёме; на других платформах часть
  функций может отличаться по качеству голосов или быть недоступна — если кнопка неактивна, наведите на неё
  курсор, там указана причина.
