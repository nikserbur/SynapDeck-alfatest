# 05. Таблицы

## Создание и работа с ячейками

Новая таблица — кнопка «+ Таблица» над деревом или правый клик по папке → «Новая таблица». Дальше это привычная
электронная таблица: столбцы, строки, ввод значений, форматирование ячеек (шрифт, цвет, границы, объединение),
формулы через `=`, ссылки на другие ячейки (`=A1+B2`), встроенные функции (суммы, средние, условия и так далее).

Панель формул сверху показывает и позволяет редактировать формулу активной ячейки. Поддержаны сортировка и
фильтры по столбцам (кнопка на панели инструментов), условное форматирование (выделение ячеек по правилу —
например, красным, если значение больше порога).

## Ссылки на другие документы прямо в ячейке

В любую ячейку можно вставить ссылку на заметку или другую таблицу — так же, как `[[…]]`-ссылки в заметках:

```
[[sheet:Название таблицы]]
[[Название заметки]]
```

Ссылка отображается в ячейке как кликабельный, выделенный цветом текст. Двойной клик по такой ячейке открывает
целевой документ в новой вкладке — удобно, например, чтобы в сводной таблице проекта держать ссылки на подробные
заметки по каждой строке.

## Избранное

Звёздочка на вкладке или в контекстном меню таблицы добавляет её в «Избранное» — быстрый доступ через фильтр в
дереве («Фильтр» → «Избранное»), не нужно каждый раз искать таблицу по всей структуре папок.

## Практический пример

Сводная таблица из выбранных заметок: выделите несколько заметок в дереве (`Shift`/`Cmd`+клик), правый клик →
«Создать сводную таблицу» — получите новую таблицу со строкой на каждую выбранную заметку и ссылкой на неё в
первом столбце — быстрый способ собрать обзорную таблицу по теме, которую вы уже разложили на отдельные заметки.
